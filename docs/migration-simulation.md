# مركز محاكاة الترحيل — Enterprise Migration Simulation, Digital Twin & AI Validation

المرحلة ٥ من **Migration Intelligence Platform**. مختبر كامل يحاكي الترحيل
الحقيقي قبل الضغط على زر التنفيذ.

> **Never Touch Production Before Simulation.** أي Migration لا تمرّ بمحاكاة
> كاملة تُعتبر غير آمنة. كل العمليات داخل **Digital Twin** في الذاكرة —
> **لا كتابة ولا اتصال ببيانات الإنتاج**، ولا تُخزَّن صفوف خام (مشتقّات فقط).

## الـ Digital Twin

نسخة رقمية للنظام الجديد في الذاكرة: جداول (`Map<entity, rows>`)، فهارس
مفاتيح (`keyCounts`)، وعلاقات. تُبنى بإعادة تنفيذ الـPipeline على بيانات
عيّنة مُقدَّمة، وتُتلَف بنهاية المحاكاة (وهو ما يجعل التراجع آمنًا بطبيعته).

## Migration Replay Engine — خطوة بخطوة

يعيد تنفيذ كل خطوات الترحيل داخل الـTwin، وسجلّ لكل خطوة (أي خطوة فشلت ولماذا):
```
Extract → Clean/Transform → Validate → Load → Relationships → Business → Constraints → Indexes → Permissions
```
لكل صفّ: `transformRow` (تحويل) → متحقّقات → `decideRow` (مصير: migrate/skip/
archive) → تحميل في الـTwin. الأخطاء تُلتقط ولا توقف المحاكاة.

## خطوط التحقّق

- **Difference Analyzer** — عدد السجلات لكل كيان؛ الفرق المتوقَّع (تخطّي/أرشفة/
  فشل) مقابل غير المتوقَّع (فقدان صامت).
- **Referential Integrity** — FK/Parent-Child/Many-to-Many/Recursive/Composite،
  كشف Broken/Orphan والدورات (Circular).
- **Business Consistency** — سلامة العدّ، اكتمال الهوية، عدم انهيار الإجماليات
  المالية (أرصدة/فواتير/مخزون)، القيم السالبة.
- **AI Validation** — طبقة استشارية **فوق** التقرير الحتمي (تحقّق تجاري +
  تنبّؤ مخاطر + توصيات)، مستندة للذاكرة المؤسسية، **لا تخترع أرقامًا**.

## محاكاة الأداء والأعطال والتراجع

- **الأداء** — استقراء إلى ١٠٠ألف/مليون/١٠ملايين: الزمن، ذروة الذاكرة/المعالج،
  التخزين، النطاق، التوقّف. + إستراتيجية Batch/Queue/Parallelism/Retry/Resume مثلى.
- **الأعطال** — شبكة/كهرباء/تعطّل DB/فشل API/تخزين/طابور/ذاكرة/ترحيل جزئي →
  قدرة الاستئناف/الاستعادة/الإعادة الآمنة (استنادًا لطابور 0073 المتعادل).
- **التراجع** — تراجع افتراضي كامل: نجاح، زمن تقديري، بلا فقدان، تغطية الكيانات.

## Migration Approval Score + قواعد المنع

الدرجة (٠-١٠٠) = مزيج مرجَّح: نجاح المحاكاة، التحقّق، السلامة التجارية،
الأداء، المخاطر، التراجع. **قواعد المنع** (أي منها يحظر الترحيل الحقيقي):

- فقدان بيانات
- علاقات مكسورة
- فشل قاعدة عمل
- أخطاء حرجة
- فشل التراجع

`verdict`: `ready` (≥٩٠ بلا منع) · `ready_with_warnings` (≥٧٠) · `not_ready`.

## سير الاعتماد (Human Approval Workflow)

Director/Admin فقط: اعتماد/رفض/إعادة/أرشفة/تنزيل التقارير. **المحاكاة المحظورة
لا يمكن اعتمادها إطلاقًا.** الاعتماد يُرقّي الدروس (أفضل Batch، ترتيب الجداول،
الأخطاء وحلولها) للذاكرة المؤسسية (حاجز مراجعة المدير) لتحسين ترحيلات المستقبل.

## الجاهزية للمرحلة ٦ (Enterprise Production Migration Engine)

المرحلة ٥ تُنتج **قرار Go/No-Go موثّقًا** بدرجة اعتماد وقواعد منع صارمة +
إستراتيجية دفعات مثلى + خطة تراجع مختبَرة. هذا بالضبط مدخل الترحيل الحقيقي:
Phase 6 تنفّذ المحرّك المعتمَد على الإنتاج بأمان — لا يبدأ إلا بعد محاكاة
جاهزة غير محظورة. **جاهز للانتقال للمرحلة ٦.**
